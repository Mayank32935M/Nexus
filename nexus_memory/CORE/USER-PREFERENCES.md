# User Preferences & Working Style

## Technical Preferences
- **Architecture**: Modular, strongly typed, clean boundaries, decoupled services.
- **Language & Frameworks**: Modern Python (FastAPI, Pydantic), TypeScript (React, Vite, Tailwind).
- **Aesthetic**: Premium technical dark-first interface, minimal visual clutter, high information density, subtle accents.
- **Data Integrity**: Never overwrite files silently. Always provide undo/audit trail.

## Communication & Interaction
- Concise, precise, high-signal engineering responses.
- Grounded claims backed by verified tests.
- Transparent reporting of failures or limitations.
